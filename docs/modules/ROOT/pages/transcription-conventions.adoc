= Transcription conventions — ParlaBZ
:guidelines-version: 1.0

ParlaBZ follows the xref:portal:transcription-conventions.adoc[KIParla
transcription conventions], version {guidelines-version}.

The sections below are the *only* points where ParlaBZ differs from or adds
to the shared conventions. Anything not listed here follows the shared page
unchanged.

== Extensions

Symbols or uses that the shared conventions do not define, added by ParlaBZ.

=== `.h` — inhalation

A standalone `.h` (also `.hh`, `.hhh`, ...) marks an inhalation, as in Jefferson notation. It is
breathing, not a word: in the verticalized files the token has type `nonverbalbehavior` (not
`linguistic`), also inside an overlapping span (`[.h]`), and it is left out of the orthographic
text. The transcription keeps `.h`. A plain `h` without the dot is not an inhalation and is
transcribed as the word it stands for.
