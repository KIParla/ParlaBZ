= Transcription conventions — ParlaBZ
:guidelines-version: 1.0

ParlaBZ follows the xref:portal:transcription-conventions.adoc[KIParla
transcription conventions], version {guidelines-version}.

The sections below are the *only* points where ParlaBZ differs from or adds
to the shared conventions. Anything not listed here follows the shared page
unchanged.

== Extensions

Symbols or uses that the shared conventions do not define, added by ParlaBZ.

_None._

// Example:
// === `&` — reading aloud
// Placed before a token read aloud from a written source.
// See xref:portal:transcription-conventions.adoc#code-switching[] for the
// analogous case.

== Overrides

Cases where ParlaBZ applies a different or stricter rule than the shared
conventions.

_None._

// Example:
// === Short pause `(.)` timing
// Overrides xref:portal:transcription-conventions.adoc#pauses[Pauses]: in
// ParlaBZ `(.)` is used only for pauses below 0.15 s; longer silences are
// always timed.
